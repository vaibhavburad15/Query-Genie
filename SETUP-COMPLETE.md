## 🚀 How to Use

### Step 1: Prerequisites (5 minutes)

Install these if you haven't:

```batch
# Download and install:
# 1. Node.js from https://nodejs.org/
# 2. Python from https://www.python.org/

# Then install PyInstaller:
pip install pyinstaller
```

### Step 2: Prepare Icons (2 minutes)

Create or convert icons:

1. **Use Query Genie logo:**
   - Find: `Query-frontend\src\assets\query-genie-logo.png`
   - Convert to .ico at: https://convertio.co/png-ico/
   
2. **Save as:**
   - `query-genie-msi\build\icon.ico`
   - `query-genie-msi\build\installerIcon.ico`

### Step 3: Build MSI (10 minutes)

```batch
# Navigate to the MSI folder
cd query-genie-msi

# Run the master build script
build-all.bat
```

This will:
1. Install Electron dependencies
2. Build Python backend with PyInstaller
3. Build React frontend with Vite
4. Create MSI installer with electron-builder

### Step 4: Test Your Installer

```batch
# Your MSI is ready at:
cd dist
dir *.msi

# Install and test:
Query Genie Setup 1.0.0.msi
```

## 🔧 Key Files Explained

### `main.js` (Electron Main Process)
- Manages the application window
- Starts/stops Python backend
- Handles auto-updates
- Creates system tray icon
- Manages app lifecycle

### `preload.js` (Security Bridge)
- Safely exposes Electron APIs to frontend
- Provides backend URL to React app
- Implements security best practices

### `package.json` (Configuration)
- Electron settings
- Build configuration
- MSI installer options
- Auto-update settings
- Dependencies

### `build-all.bat` (Master Build)
- Installs dependencies
- Builds backend
- Builds frontend
- Creates MSI
- One command does everything

### `build-backend.bat` (Backend Builder)
- Uses PyInstaller
- Creates standalone .exe
- Bundles all dependencies
- Includes database and configs

### `build-frontend.bat` (Frontend Builder)
- Uses Vite build
- Optimizes React app
- Creates production bundle
- Copies to Electron folder

## 🎨 Customization Options

### Change App Name
Edit `package.json`:
```json
{
  "name": "your-app-name",
  "productName": "Your App Display Name"
}
```

### Change Version
Edit `package.json`:
```json
{
  "version": "1.0.1"
}
```

### Change Icons
Replace files in `build/` folder:
- `icon.ico` - App icon
- `installerIcon.ico` - Installer icon

### Configure Auto-Update
Edit `package.json`:
```json
{
  "build": {
    "publish": {
      "provider": "github",
      "owner": "your-github-username",
      "repo": "query-genie"
    }
  }
}
```

See `CONFIGURATION-GUIDE.md` for complete options.

## 🐛 Common Issues & Solutions

### "Python not found"
```batch
# Add Python to PATH
setx PATH "%PATH%;C:\Python310;C:\Python310\Scripts"
```

### "npm install fails"
```batch
npm cache clean --force
rmdir /s /q node_modules
npm install
```

### "Backend won't start after install"
- Check port 8000 is available
- Run backend manually: `resources\backend\query-genie-backend.exe`
- Check firewall settings

### "Icons not found"
- Add `icon.ico` and `installerIcon.ico` to `build/` folder
- Or continue without (not recommended for production)

See `INSTALLATION-GUIDE.md` for complete troubleshooting.
