# 🧞 Query Genie MSI Installer - START HERE

## 🎯 What is This?

This folder creates a **Windows MSI installer** for Query Genie that packages:
- ✅ React Frontend (UI)
- ✅ Python Backend (FastAPI server)
- ✅ Electron Wrapper (Desktop app experience)
- ✅ Auto-Update System
- ✅ Desktop & Start Menu Shortcuts

## ⚡ Quick Build (3 Commands)

```batch
# 1. Add icons to build/ folder (icon.ico & installerIcon.ico)
#    See build/README.md for instructions

# 2. Run the master build script
build-all.bat

# 3. Find your MSI installer
dir dist\*.msi
```

**Done!** Your installer is at: `dist\Query Genie Setup 1.0.0.msi`

## 🎨 Before Building - Add Icons!

**IMPORTANT:** The build will fail or warn if icons are missing.

### Quick Method:
1. Go to: https://convertio.co/png-ico/
2. Upload: `..\Query-frontend\src\assets\query-genie-logo.png`
3. Download as `icon.ico`
4. Make a copy: `installerIcon.ico`
5. Place both in `build/` folder

### Icon Requirements:
- **Format:** .ico (Windows Icon)
- **Size:** 256x256 pixels
- **Files needed:** 
  - `build/icon.ico` (app icon)
  - `build/installerIcon.ico` (installer icon)

See `build/README.md` for details.

## 🎬 Quick Start Script

Copy and paste this into your command prompt:

```batch
@echo off
echo === Query Genie MSI Builder ===
echo.

echo Checking prerequisites...
where node >nul 2>&1 || (echo ERROR: Node.js not found! && pause && exit)
where python >nul 2>&1 || (echo ERROR: Python not found! && pause && exit)
pip show pyinstaller >nul 2>&1 || (echo Installing PyInstaller... && pip install pyinstaller)

echo.
echo Prerequisites OK!
echo.
echo Building MSI installer...
echo This will take about 10 minutes.
echo.
pause

build-all.bat
```

## 🐛 Quick Troubleshooting

### Build fails?
```batch
# Check prerequisites
node --version  # Should be v18+
python --version  # Should be 3.10+

# Clean and retry
rmdir /s /q node_modules
npm install
build-all.bat
```

### Icons not found?
```batch
# Add placeholder icons
echo "Add icon.ico and installerIcon.ico to build/ folder"
# See build/README.md
```

### Backend won't start?
```batch
# Test backend manually
cd resources\backend
query-genie-backend.exe
```
